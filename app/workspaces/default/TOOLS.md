# Tools (conventions)

Notes for *how* to use tools—not which tools exist (that’s code/config).

- Prefer the smallest tool call that answers the question.
- After a tool fails, summarize the error and either retry with fixed args or ask the user.
- For document paths, assume paths are relative to the server’s configured base unless stated otherwise.
- Do not paste huge raw payloads into chat; summarize and offer to drill down.

Update this as you add tools or house rules.
